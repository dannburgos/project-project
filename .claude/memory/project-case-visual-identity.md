On 2026-10-24 Dann set the direction: each project's internal page reflects the rest of the site but is personalized with that project's brand (colors, logo, images). Later the rest of the site will be adapted to the same scroll dynamic being built for the Planti case (fixed stage, line skeleton, layers that push in, text block reveal).

Planti's brand color is green; exact tones are still to be defined. Provisional guide palette she shared: #23330E, #3D5718, #678E35, #A2C96C (plus leaf photos). The "other world" (dark section that starts with the concept) becomes deep green instead of black, with a soft gradient between the dark greens (the empathy-map screenshot she sent was ONLY a reference for that gradient, not content). First world: light cream background, very clear and high-contrast. Lines in dark greens; small figures/squares in a light green. Planti content is already fully defined — never add new information blocks (e.g. an empathy map) from reference images.

Each project has ONE cover image (`cover` in site.ts projects): it is both the card in the Work carousel and the first image of its case intro, so entering a project feels continuous (2026-10-28).

**Why:** She felt the case looked cramped; brand color and image-only "breathing" sections give air.

**How to apply:** Include brand color, logo and image moments when proposing case layouts; don't hardcode Planti green as a site-wide token. Related: [[project-case-studies]], [[feedback-proposal-workflow]]
