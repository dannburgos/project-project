# Product profile — Encuentra tu Toyota

| Campo | Definición |
|---|---|
| Producto | "Encuentra tu Toyota": módulo de asesoría en el home de Toyota Colombia (caso de portafolio *Toyota — Beyond the Model*) |
| Tipo | Experiencia web desktop de descubrimiento y recomendación |
| Industria | Automotriz, vehículos nuevos |
| Mercado / idioma | Colombia · español de Colombia |
| Audiencia | Personas que piensan comprar un carro nuevo y necesitan orientación (primer carro, cambio de necesidades, renovación). Cualquier nivel de conocimiento automotriz |
| Objetivo del usuario | Saber qué Toyota se adapta a su vida y por qué |
| Objetivo del negocio | Conectar necesidades con el portafolio Toyota antes de cotizar |
| Trato | Tú (**supuesto**, inferido del sitio toyota.com.co: "Encuentra el Toyota perfecto para ti", "Cotiza tu Toyota") |
| Formalidad | Cercana, clara, sin tecnicismos |
| Nivel de lectura | Cotidiano: cualquier persona sin conocimientos de carros entiende cada pregunta |
| Voz | **Supuesto:** asesor que pregunta sin presionar. Útil, directo, sin exagerar beneficios |
| Restricciones | No inventar datos, precios ni beneficios. No presionar la decisión. No mencionar la IA como protagonista |

**No hay manual de marca disponible.** La voz se infirió del sitio actual de Toyota Colombia y de las decisiones del caso. Revisar si aparece un manual.
