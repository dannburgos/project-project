# Terminología — Encuentra tu Toyota

| Concepto | Término aprobado | No usar |
|---|---|---|
| El producto que se compra (en la asesoría) | carro | auto, coche, automóvil (salvo como categoría) |
| Categorías | Automóvil · Camioneta o SUV · Pick-up (como en toyota.com.co) | sedán, hatchback como categoría |
| Resumen de respuestas | Tu perfil | Mi perfil, resumen |
| Lo que el usuario no negocia | No cederías / indispensable | obligatorio, requisito |
| Respuesta de incertidumbre | Aún no lo sé | No estoy seguro/a (marca género) |
| Sin preferencia | No tengo preferencia | Me da igual |

**Persona:** la interfaz le habla al usuario con "tu" (Tu perfil). Las opciones de respuesta se escriben en primera persona, con la voz del usuario ("Voy a comprar mi primer carro").
